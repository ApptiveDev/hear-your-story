# 출시 QA 실행과 결과 기록

## 실행 기준

설치한 APK/AAB의 버전·빌드 번호·커밋과 서버 환경/버전을 먼저 기록한다.
Mock 검증과 실제 서버 검증을 분리하며, 준비되지 않은 기능은 PASS 대신 BLOCKED로 둔다.
서버 작업 중단·토큰 만료·삭제 검증은 담당자와 합의한 테스트 환경과 데이터로만 실행한다.

| ID | 시나리오 | 확인할 결과 |
|---|---|---|
| Q01 | 설치·앱 재시작 | 설치 성공, 대상 환경에서 의도한 시작 화면 |
| Q02 | 부모·자녀 가입·페어링 | 양쪽이 같은 Pair로 연결, 잘못된/만료된 코드 안내 |
| Q03 | 마이크 거부→허용 | 거부 안내 후 권한 허용 시 녹음 가능 |
| Q04 | 녹음→멈춤→이어가기 여러 번 | 파일 하나로 재생, 멈춘 시간 제외, 중복 업로드 없음 |
| Q05 | 멈춤→처음부터 다시 말하기 | 취소하면 기존 녹음 유지, 확인하면 이전 음성 제거·시간 초기화 |
| Q06 | 실제 녹음 합계 60초 | 자동 종료, 멈춘 동안 시간 증가/자동 전송 없음 |
| Q07 | 전화·백그라운드 전환 | 의도하지 않은 전송 없음, 복귀 후 파일/상태 확인 |
| Q08 | 업로드 중 네트워크 단절→복구 | 오류/재시도 가능, 같은 답 중복 생성 없음 |
| Q09 | 부모 음성·자녀 글 제출 | 양쪽 제출 전 비공개, 제출 후 공개·원본·요약·TTS 확인 |
| Q10 | 오디오 URL 만료 후 재생 | 새 URL로 재생, 무한 로딩/중복 재생 없음 |
| Q11 | 월별 달력 | 다른 달·빈 달·날짜 선택·월 복귀, 양쪽 역할의 음성 재생 |
| Q12 | 글씨 1.3배·2배 | 주요 버튼 접근 가능, 안내/본문 잘림 없음 |
| Q13 | 카카오 로그인·만료·재설치·기기 변경 | 계약/서버 준비 후 실행. 같은 계정의 Pair·기록 복구 |
| Q14 | 내 답 삭제·회원 탈퇴 | API 준비 후 실행. 본인 자료만 삭제, 상대 화면/DB/R2 결과는 담당자와 확인 |
| Q15 | 마이페이지 | 로그아웃, 처리방침·문의·버전과 실제 빌드 일치 |

## 결과 양식

아래를 테스트 PR 본문 또는 팀이 합의한 QA 기록에 복사한다.
녹음 원문, 개인 계정 정보, 토큰, 서명 URL, 서버 비밀값은 첨부하지 않는다.

```text
검증 일시 / 검증자:
앱 버전+빌드 번호 / 커밋:
환경 이름 / 서버 버전:
부모 기기·Android 버전:
자녀 기기·Android 버전:
활성화된 기능 / Mock 여부:

ID | PASS / FAIL / BLOCKED / NOT_RUN | 관찰 결과 | 버그 링크 | 재검증 빌드
Q01 | NOT_RUN | | |
```

버그는 재현 순서, 기대 결과, 실제 결과, 발생 빈도와 영향을 적는다.
로그·스크린샷에서 민감정보를 가린 뒤 첨부한다. 수정 PR이 병합돼도 같은 시나리오를
새 빌드에서 재검증하기 전에는 검증 완료로 바꾸지 않는다.

## 빌드 배포 기록

| 배포일 | 앱 버전/번호 | 소스 커밋 | 환경/서버 버전 | 설치 파일 SHA256 | 배포 채널 | QA 결과 |
|---|---|---|---|---|---|---|

설치 파일 해시와 커밋은 빌드 스크립트가 생성한 `build-info.json`에서 가져온다.
CI 통과와 APK 생성은 실기기 검증을 대신하지 않는다.
